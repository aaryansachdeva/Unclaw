## Design Context

### Users

Desktop users running an Unreal Engine pixel-streamed 3D AI character as a personal companion. They interact via text and voice through a 420x760 always-on-top Electron window that floats on the side of the display. The character responds with speech, lip-synced animation, mood-driven facial expressions, and montages (kiss, dance, hello). Range: tech-savvy early adopters → casual users who want an AI presence on screen.

The pixel stream is the experience. The character lives over a dark navy background; the chrome lives in the margins.

### Brand Personality

**Sleek, intimate, alive.** UnClaw is a presence, not a tool. The interface should feel like a portal to another being — warm despite the dark palette, restrained despite the depth of features behind it. Think a luxury device that wakes up to greet you, with a personality you'd actually miss if it were gone.

3-word personality: **warm · present · refined**.

### Aesthetic Direction

- **Reference**: Apple Vision Pro materials, the macOS Sequoia translucent control language, Apple TV+ overlay player chrome — frosted slate panels floating over moving image content.
- **Theme**: Dark-only. The pixel stream provides ambient color (dark navy + the character's skin/clothes); chrome stays a desaturated frosted slate that coexists with the stream rather than competing.
- **Materials**: Frosted slate glass — `rgba(40, 48, 65, x)` family, never inky black, never light-on-dark. Strong blur (32–40 px) with saturation boost (1.6–1.7) so the material feels truly translucent rather than tinted.
- **Typography**: Plus Jakarta Sans — warm, rounded, characterful. Body 12–13.5 px. Display sizes for the Greeting and the weather temperature. Uppercase used sparingly with `0.04–0.06em` letter-spacing (never the wide `0.10em` corporate look).
- **Motion**: Framer Motion. Spring + ease-out-expo. Nothing flashy. Greeting fades in with a tiny y-offset; pills swell on hover; panels grow upward via `bottom: calc(100% + 8px)`; voice bars react in real-time to VAD probability. Animations should feel **organic** (breathing, morphing) not **mechanical** (snapping, blinking).

### Anti-References

- ChatGPT / Discord chatbot UI (white bubbles, message lists, sterile chrome).
- Gamer/RGB aesthetics (neon, aggressive angles, gaming-overlay vibes).
- Corporate dashboard patterns (cards, charts, sidebar nav, enterprise SaaS).
- Skeuomorphic/heavy chrome (drop-shadows-as-decoration, fake textures, thick borders).
- Inky-black "video player overlay" — surfaces that compete with the stream as a competing dark mass.
- Light-on-dark glass tinted with white-alpha — disappears against bright skin tones.

### Hierarchy

The pixel stream is the **primary** experience. UI is **significant but lateral** — it lives in the margins (bottom row, top corners) and never competes for the eye when the user isn't actively engaging it.

This produces a layered material strategy:

| Layer | Material | Always visible? |
|---|---|---|
| **Primary chrome** (AgentSwitcher, InputBar) | Frosted slate, `--glass-bg` | Yes — these are how you steer |
| **Ambient widgets** (Reminders, Stocks, News, Weather pills) | Hover-only glass; floating icon + label at rest with text-shadow | No — wake up only when you reach for them |
| **Expanded panels** (any widget when open) | Frosted slate, `--glass-bg-panel` (slightly heavier than `--glass-bg-hover`) | Only while open |
| **Voice indicator** (inside the input bar's circular button) | Inherits the input bar's surface | When voice mode is active |

### Design Principles

1. **Stream is the star.** Chrome lives in the margins; the character holds the center. If a UI element ever obscures the character's face, redesign it.
2. **Frosted slate, never inky black.** Surfaces use `rgba(40, 48, 65, x)` so they pick up the stream's navy ambient and read as translucent material — not a flat dark slab.
3. **Two intensities, one material.** Primary controls are always present at low intensity; ambient widgets sleep at zero intensity and wake on hover. Same glass language, different opacity stops.
4. **Whisper, don't shout.** Small text, subtle borders, sparse accent use. Confidence comes from restraint, not size.
5. **Breathe, don't blink.** Animations use spring + ease-out-expo. Nothing snaps.
6. **The accent is precious.** Warm red `#c44444` appears only at moments of attention — focus states, the transcribing-bars wave, error chips. If everything is accent, nothing is.
7. **Text-shadow over backdrop where possible.** When a label floats on the stream without a chrome surface (hover-only pills at rest), use a `0 1px 2px rgba(0,0,0,0.55)` text-shadow + matching `drop-shadow` filter on icons. Keeps content legible without forcing chrome to appear.

### Design Tokens

```css
/* Surfaces */
--glass-bg:           rgba(40, 48, 65, 0.32);   /* always-on primary chrome (AgentSwitcher, InputBar) */
--glass-bg-hover:     rgba(40, 48, 65, 0.48);   /* pill hover state — subtle reveal */
--glass-bg-panel:     rgba(40, 48, 65, 0.52);   /* expanded widget panels — slightly heavier for content */
--glass-border:       rgba(255, 255, 255, 0.12);
--glass-border-focus: rgba(255, 255, 255, 0.20);
--glass-blur:         blur(36px) saturate(1.7);

/* Text */
--text-primary:   #fafafa;   /* near-white — primary copy on chrome */
--text-secondary: #b8b3ad;   /* warm grey — meta, subtitles, section labels */
--text-ghost:     #6e6862;   /* faintest — separators, decorative only, NEVER body content */

/* Accent (warm red — moments of attention) */
--accent:        #c44444;
--accent-dim:    rgba(196, 68, 68, 0.08);
--accent-glow:   rgba(196, 68, 68, 0.14);
--accent-strong: rgba(196, 68, 68, 0.32);

/* Status */
--live:   #8cbf8a;   /* sage green — speaking / up-day / online */
--danger: #f87171;   /* error red — keep separate from accent */

/* Easing */
--ease-out-expo:  cubic-bezier(0.16, 1, 0.3, 1);
--ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1);
```

### Materials By Component

- **AgentSwitcher**: always-on `--glass-bg`, 14px radius, 8x12 padding, 24x24 chevron buttons.
- **InputBar**: always-on `--glass-bg`, 24px radius (pill), focus → `--glass-bg-hover`.
- **Voice button** (inside InputBar): white circular at rest with dark wave glyph; transitions to mini bars when voice mode activates.
- **Widget pills** (Reminders/Stocks/News/Weather): `transparent` at rest with text-shadow + drop-shadow on label/icon; `--glass-bg-hover` on hover or open. 14px radius, 8x14 padding.
- **Widget panels** (when open): `--glass-bg-panel` + `blur(36px) saturate(1.7)` + 1px highlight inset + grounded drop-shadow. 16px radius, 14–16px padding.
- **Greeting** (top-left): no chrome — Plus Jakarta Sans display + italic quote, drop-shadowed for legibility.
- **Titlebar** (top-right): pill icons (pin / minimize / close) on `--glass-bg`.

### Accessibility

- Reduced-motion media query in `styles.css` cuts every animation to 10ms — required for vestibular sensitivity.
- Color contrast: `--text-primary` (#fafafa) on `--glass-bg-panel` clears WCAG AA. `--text-secondary` clears AA at body sizes. `--text-ghost` is decorative-only, never used for content.
- Voice mode is keyboard-accessible (mic button focusable; ARIA-labelled).
- Pill labels carry both `aria-expanded` and dynamic `aria-label` for screen readers.

### What's NOT Encoded Yet

- Light mode (none planned — the character lighting is calibrated for dark UI).
- Mobile/responsive (Electron desktop only; would need a separate adaptation if it ever moves to web).
- Brand mark or logo treatment beyond the "UNCLAW" wordmark in the titlebar.
